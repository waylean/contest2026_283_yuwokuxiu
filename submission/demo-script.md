# 五分钟 Demo 脚本

目标时长：4 分 40 秒至 4 分 55 秒。视频不得超过 5 分钟。

## 0:00-0:25 用户问题

- 展示真实羽毛球场景和小米手环 10 Pro。
- 旁白：普通球友很难持续使用雷达或高速摄影，BMT Smash 利用持拍手腕的
  加速度提供随身训练参考。
- 屏幕明确显示“预测球速为训练估计，不是雷达实测”。

## 0:25-1:20 独立训练流程

- 打开应用，快速展示持拍手、身高和表带设置。
- 开始训练，进行一次有效挥拍和一次普通摆臂。
- 展示实时波形、有效挥拍、挥拍强度和预测球速。
- 暂停、继续并结束训练。

## 1:20-2:05 完整产品体验

- 展示当前、平均和最高心率；同时说明心率不可用不影响挥拍检测。
- 展示结束后的历史记录和冷启动恢复。
- 展示独立计分和明确退出，强调核心流程不依赖手机或网络。

## 2:05-3:00 算法与误判处理

- 使用一张简洁数据流图讲解候选窗口、峰值、jerk、冲量、方向一致性和回位
  过滤。
- 对比有效挥拍、普通摆臂、碰撞和回位回放结果。
- 展示真实设备指标表，不宣称雷达级精度。

## 3:00-3:45 openvela 工程实现

- 展示 `system.sensor`、`service.health`、`system.storage`、图形和路由能力。
- 展示 JSC-only 构建、模拟器传感器 Mock 和冷启动历史恢复。
- 说明传感器回调与 80 ms 图形刷新分离，以及停止后的延迟回调保护。

## 3:45-4:25 AI-Native 工作流

- 展示官方 AI Coding 日志、可复用 Skill 和自动审计结果。
- 展示一次“需求 -> 修改 -> 回放 -> 构建 -> 模拟器 -> 盲审”的闭环。
- Token 数据只使用官方采集器可核实结果。

## 4:25-4:50 产品验证与结尾

- 展示匿名化用户数量、支持设备和代表性反馈。
- 总结：BMT Smash 让 openvela 手环成为无需额外设备的羽毛球训练工具。

## 拍摄安全线

- 使用预录实机片段，避免现场投屏失败。
- 心率不可用时展示降级文案，不中断 Demo。
- 离线保留代码、模拟器截图和构建录像。
- 状态栏、邮箱、设备 AuthKey、聊天头像和付款信息必须裁切或打码。

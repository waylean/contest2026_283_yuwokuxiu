## Codex CLI 兼容性记录

当前赛事归集器可以发现 Codex CLI 会话文件，但尚不能从本机当前 Codex rollout
结构中生成赛事 JSONL。手工运行官方 snapshot hook 同样没有产生事件，因此判定为
归集器与当前 Codex CLI 日志结构的兼容问题，而不是仓库路径或 hook 安装错误。

在官方归集器修复前：

1. 不伪造或手工回填 Codex 历史日志；
2. 对后续关键参赛任务使用归集器明确支持且已验证的 Claude Code CLI；
3. 保留 Codex 原始会话，但提交前仍执行敏感信息扫描；
4. 在开发日志中如实记录工具、日期、任务目标、产出和验收结果；
5. 归集器更新后，再用官方命令测试是否能够合法补采原始 Codex 会话。

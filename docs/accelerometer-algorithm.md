# 三轴加速度挥拍算法

## 目标与边界

算法目标是在手环独立运行、只有三轴加速度的条件下，稳定识别“具有挥拍形态的
腕部动作”，并提供可比较的训练强度。它不恢复完整球拍姿态，不把预测球速描述为
雷达实测，也不根据一次加速度峰值直接给出高分。

## 处理链路

```text
20 ms 级加速度回调
  -> 指数低通估计重力
  -> 动态三轴分量、模长、jerk
  -> 静止噪声估计与有界自适应阈值
  -> 候选动作窗口
  -> 多特征质量门控
  -> 相邻事件方向与强弱关系
  -> 强度和预测球速估计
```

### 1. 重力分离

对三轴原始值进行时间常数约 0.82 秒的指数低通，得到缓慢变化的重力分量。原始值
减去重力后得到动态分量。检测同时参考动态分量模长和原始模长相对重力的变化，
降低手环朝向变化造成的漏检。

### 2. 有界自适应阈值

应用只在当前没有候选窗口，并连续约 0.5 秒处于严格静止包络时更新噪声基线。
触发阈值由基线噪声和实测回调间隔计算，但被限制在保守上下界内：

- 安静佩戴时不会低于原有固定门槛；
- 表带振动或设备噪声持续增加时，门槛缓慢提高；
- 单次异常峰值不会直接抬高基线；
- 回调变慢时只做有限补偿，不允许无限放宽。

因此自适应用于抵抗设备和佩戴差异，不用于追随动作强度。

### 3. 多证据质量门控

候选窗口同时计算：

- 峰值动态加速度；
- 峰值 jerk；
- 加速度平方积分和冲量；
- 峰值相对平均值的突发比；
- 三轴净冲量的方向一致性；
- 持续时间、峰值位置和半高宽；
- 近期中等峰值的周期性。

只有多项证据共同满足条件才计为有效挥拍。新增的窄脉冲门控会拒绝“单个高峰、
半高宽极短、相对冲量不足”的碰撞信号，避免碰桌、敲击或手持设备猛甩仅凭峰值
获得高强度。

### 4. 回位与快速连续挥拍

每次有效事件保留三轴净冲量方向。后续候选在 1.05 秒内出现时，算法比较：

- 峰值比例；
- 冲量比例；
- 估计速度比例；
- 两次净冲量方向的余弦关系。

方向只作为辅助证据：明显较弱且方向反转的动作优先判为击球后回位；强度接近的
反向动作以及方向基本一致的快速连续挥拍，不会仅因方向或时间接近而被过滤。方向
信息不足时使用原有保守规则降级。由于没有陀螺仪和世界坐标姿态，三轴方向不被
解释为球拍在空间中的绝对方向。

## 强度与球速

腕部速度由动态加速度、jerk 恢复项和冲量代理共同估计，再根据身高对应的腕部到
球拍几何关系、表带松紧修正和信号质量门控换算为球拍速度代理。预测球速使用有
界恢复系数和击球质量系数，并受分档上限约束。

上限不是证明准确度的依据。低质量、方向不稳定或拖长的信号即使峰值很高，也无法
进入高速度分档。输出始终标注为训练估计值。

## 可重复性质测试

自动测试不声称替代真实球场准确率，只验证算法应始终满足的性质：

| 性质 | 验收条件 |
| --- | --- |
| 坐标轴置换与符号变化 | 检出数不变，强度差不超过 2 |
| 动态幅值缩小 | 强度不得增加 |
| 动态幅值增大 | 有效动作强度不得下降 |
| 固定 20/30 ms 回调夹具 | 保持检出，强度差处于预设界限 |
| 30–70 m/s² 单脉冲与窄双脉冲矩阵 | 不得计为挥拍 |
| 快速同方向连续动作 | 不得仅因时间接近判为回位 |
| 较弱反向动作 | 应判为回位 |
| 普通摆臂、跑动和静止 | 特征夹具不得计为有效挥拍 |
| 强度分档 | 有效动作增强时保持单调且不超过物理上限 |

## 后续校准原则

未来获得包含视频、击球类型和人工复核的真实球场标注后，才计算 precision、
recall 和每小时误报数。数据集必须预先划分训练集与冻结测试集；阈值只在训练集
调整，测试集不得用于反复试错。没有这类标注前，不发布真实准确率数字。
